## Intent

Create a fast-paced cinematic launch film and coordinated explanatory images for Mac Guardian. The user explicitly requested a doctor-with-computer logo, impressive creative ideas, English language, and HyperFrames motion design. This is a product promo using the supplied product brief, not a site tour. No website capture is required.

Creative direction: Your Mac has a doctor now. A friendly sculpted physician with a laptop anchors a confident near-black, ivory, and luminous mint identity. Oversized type, heartbeat geometry, spatial file choreography, and decisive cuts carry the story. A bespoke instrumental score punctuates the transformations. No voiceover so the film works muted on the index.

## Notes

User-stated: English, images explaining the project, doctor/computer logo, fast-paced cinematic video, HyperFrames, Agent Index destination, creative autonomy ("me impressione").
Decisions: 40 seconds, 1920x1080, instrumental sound, no intermediate approval rounds. These choices fit the product and an embedded launch film. The user asked for the finished video; render is within the requested work.

Factual boundaries: routine every 15 minutes; safe recreation cleanup; supported official updates when apps are idle; inventory and security checks, not a guarantee of malware detection; physical ~/Wiki with file-type categories and existing topics, not a semantic knowledge graph; contextual naming and reversible file moves; private GitHub backup only for configured authorized roots with independent verification. Do not show fake performance statistics or personal files. Documents and iCloud are excluded from organization. Do not present a dashboard as the product.

Internal concept exploration: a medical checkup in the Mac's visual world; an expanding empty workspace as relief; a conversation that disappears into completed work; a quiet night shift illustrated as a maintenance film; an abstract prescription composed from file paths. Selected the medical checkup combined with the empty-workspace payoff because it directly expresses the requested logo and silent maintenance while giving the film a distinct visual silhouette.
